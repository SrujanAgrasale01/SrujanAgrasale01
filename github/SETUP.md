# Setup

1. Open your profile repository: `SrujanAgrasale01/SrujanAgrasale01`.
2. Copy these files into that repository.
3. Commit them to the `main` branch.
4. Open **Settings → Actions → General → Workflow permissions** and choose **Read and write permissions**.
5. Open **Actions → Update Profile Art → Run workflow** once.
6. Your profile README will display the animated portrait, terminal card and contribution heatmap.

The contribution graph is generated and committed by GitHub Actions, so it updates automatically.
